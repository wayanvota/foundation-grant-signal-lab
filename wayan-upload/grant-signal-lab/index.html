      Method
      The evaluator is inspectable code.
      Open the complete fictional worked example to inspect the compiled rule, twelve-profile exclusion report, impact report, self-screen, and funnel projection without submitting data.
      Compilation is constrained
      The model may translate testable prose into a RuleSpec. Values language, quality judgments, and instructions addressed to the model remain uncompiled.
      Eligibility is deterministic
      The same RuleSpec and applicant facts produce the same status, reason code, and clause reference.
      Self-screen parity: 100/100, boundary-value suite, run 2026-09-05.
      Determinism: 20/20 repeated evaluations, run 2026-09-05.
      People retain authority
      The tool does not recommend awards, score quality, judge community representation, or predict funding probability.
      Current boundary: the tool does not run a live intake workflow or produce cohort reports from live submissions. Those functions require real call data and remain outside this release.
